# Anki с использование Django
Приложения для заучивания любой информации. Позволяет создавать карточки для активного воспроизведения информации. Карточки перемещаются по стопкам в зависимости от успешности изучения.

## Запуск
```
git clone git@github.com:apselon/DjangoHW.git
cd DjangoHw
python manage.py migrate
python manage.py runserver
```
